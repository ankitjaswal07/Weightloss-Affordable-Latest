Editorial telehealth theme for clinician-led weight-management services.

== Description ==

WeightLossAffordable is the presentation layer of a weight-loss treatment
website: forest-and-ivory palette, Fraunces headings, Manrope body text, soft
card surfaces and generous section spacing.

It renders 17 section types (hero, product showcase, services, care journey,
approach, pricing, resource explorer, reviews, FAQ, contact, subpage hero, CTA
band, page navigation, rich text, treatment grid and treatment detail) and
templates for pages, treatments, the article index, archives, search, 404 and
comments. Every section is editable in Elementor through the companion plugin,
or in the classic editor through the Page sections panel.

The theme is deliberately data-light: content lives in the *WeightLossAffordable
Core* plugin, so deactivating the plugin leaves the site intact and deactivating
the theme does not lose content.

== Installation ==

1. Install and activate the WeightLossAffordable Core plugin.
2. Upload this theme and activate it.
3. Install Elementor (free) if you want visual editing.
4. Run WeightLossAffordable -> Dashboard & import -> Import demo content.

== Frequently Asked Questions ==

= Does it need Elementor? =
No. Elementor is optional; every page also renders from stored section data.

= Does it need a child theme? =
No. Design tokens live in theme.json and the Customizer, and page content is data.

=== WeightLossAffordable Core (v2.1) ===
Requires at least: 6.6
Requires PHP: 7.4
Stable tag: 2.2.0
License: GPL-2.0-or-later

Companion plugin: Elementor widgets, live EN/ES translator, custom post types, AJAX enquiry form, Get Quote quiz, treatment catalog, and one-click demo importer.

v2.1 publishes the full clinical demo on import (quiz + treatments + English default). The quiz module is loaded from the main plugin bootstrap so submissions work end-to-end.

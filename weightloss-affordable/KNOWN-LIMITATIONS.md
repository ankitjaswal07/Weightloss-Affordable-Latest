# Known limitations and third-party integrations

- **Elementor (free)** is required to visually edit imported page layouts. Elementor Pro is not required.
- **wp_mail / SMTP** is required for enquiry notification emails. If the host does not send mail, submissions are still stored in the dashboard.
- **Clinical webhook** is optional. Configure it only after privacy and HIPAA review.
- **WooCommerce** is optional. Treatment prices can sync from a product ID if you enable that setting later.
- **Compounded GLP-1 information** is educational. It is not a substitute for FDA labeling or a clinician’s advice.
- **Example prices** in treatment records must be confirmed before any public checkout.
- **No fabricated testimonials, addresses, licenses, or review stars** are included.
- Browser QA of the live WordPress site must be repeated on the destination server; this sandbox did not run WordPress.

=== WeightLossAffordable Theme (v2.1) ===

Straw Luxury editorial WordPress theme for WeightLossAffordable: Fraunces + Manrope, homepage design preserved, treatment templates, Get Quote quiz template, Elementor canvas support, and English as the default language.

QUICK INSTALL:
1. Upload & activate weightloss-affordable.zip in Appearance -> Themes.
2. Upload & activate weightloss-affordable-core.zip in Plugins.
3. Install & activate free Elementor (Elementor Pro is NOT required).
4. Visit WeightLoss Setup -> Demo Import and click "Import Complete 100% Preview Website".
5. After import, every demo page and treatment is Published. Open /consultation-eligibility/ to use the Get Quote quiz.

See INSTALLATION.md, ADMIN-GUIDE.md and QA-REPORT.md in the project package.
